# Caiman Data — Claude Plugin Marketplace

The official [Caiman Data](https://tools.caimandata.ai) plugin marketplace for
Claude Cowork and Claude Code. **Caiman Core 0.2.22** guides setup and connects
your selected Caiman tools. Your complete VIP or GLS+ workspace kit supplies
the operating framework, saved business memory and dashboard.

**Start before Amazon is connected:** [follow the startup checklist](START-HERE.md).
Use your product facts, listing copy and reference images to prepare useful
listing changes and visual concepts. Performance reports can come later.

## Install (Claude Cowork)

1. Open the **Customize** menu → **Plugins**.
2. Under **Personal plugins**, click **+** → **Add marketplace** → **Add from a
   repository**, and enter:

   ```
   VoltageDM/caimandata-AI-plugin
   ```

3. Install or update **Caiman Core**, then enable it for the business project.
4. Choose one folder for that business and follow [Start here](START-HERE.md).
   Keep the same folder when updating. Your assistant preserves existing work.

An Amazon connection is only needed for connected account work. When you choose
that workflow, sign in through the Caiman connection requested by your assistant.
Marketplace updates and the full workspace-kit update are separate steps.

## Install (Claude Code)

```
claude plugin marketplace add VoltageDM/caimandata-AI-plugin
claude plugin install caiman-core@caimandata
```

## What's inside

| Plugin | What it does |
|---|---|
| `caiman-core` | Installs or updates the complete selected-tier kit, resumes saved local work, and routes connected work through Caiman (`mcp-amazon.caimandata.ai`). |

## Availability

The complete workspace kit is an entitled membership download, separate from
this public plugin. Your assistant checks the actual download's tier, release
and contents. Core alone does not mean the workspace kit is installed.

If the kit download is unavailable, setup stops with that specific dependency.
Do not wait for a job that has not started. Use the member support route shown
in your account to obtain the complete kit and its download verification.

The dashboard opens saved work and downloadable proposals. It does not start
background account changes. Ask Caiman in the same project to continue the next
task; it explains missing inputs and shows the result when ready.

Your subscription controls what the tools and skill library return — this
repository contains no credentials and nothing customer-specific.
